# 📊 Relatório Power BI

Este repositório contém um relatório desenvolvido em **Power BI Desktop (.pbix) para o projeto integrador IV da Univesp**.

## 🧩 Sobre o projeto

O objetivo deste relatório é apresentar visualizações e análises baseadas em um conjunto de dados (não incluído neste repositório, pois o arquivo Excel original não foi disponibilizado por conter informações locais/sigilosas).

O arquivo `.pbix` contém toda a estrutura do modelo de dados, as medidas DAX, as relações e os visuais criados no Power BI.

---

## 📁 Arquivo disponível

- `meu_relatorio.pbix` → Arquivo principal do Power BI.

> 💡 Para baixar o arquivo, clique nele e depois em **“Raw”** (Bruto) para iniciar o download.

---

## ⚙️ Como abrir o arquivo

1. Baixe o arquivo `.pbix` (via botão **Raw** ou **Download**).
2. Abra-o no **Power BI Desktop**.
3. Como o arquivo não inclui a base Excel, será necessário:
   - Atualizar a conexão de dados, ou  
   - Substituir as fontes por seus próprios dados.

---

## 🧠 Requisitos

- **Power BI Desktop** (versão atualizada)
- Conexão com a fonte de dados, caso queira atualizar o relatório.

---

## 🔒 Observação

Os dados originais não estão incluídos neste repositório por motivos de privacidade e tamanho.  
Este projeto é apenas para fins de demonstração e compartilhamento da estrutura do relatório Power BI.
